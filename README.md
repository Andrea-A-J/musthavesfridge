# MustHavesFridge


MustHavesFridge es una aplicación web para gestionar listas de la compra mediante etiquetas NFC.

La idea es sencilla: una etiqueta NFC colocada en un imán del frigorífico permite que cualquier miembro de mi familia abra instantáneamente la lista de la compra desde su móvil.

### Objetivos del proyecto

- Gestionar productos pendientes de comprar.
- Compartir una lista común entre varios usuarios.
- Acceso rápido mediante NFC.
- Compatible con Android e iPhone.
- Interfaz sencilla y responsive.
- Aprender desarrollo web, bases de datos y tecnologías NFC.

### Tecnologías previstas

- HTML
- CSS
- JavaScript
- Firebase
- NFC (NTAG215)
- NFC Tools
- GitHub
- Vercel

## English

MustHavesFridge is a web application designed to manage shopping lists using NFC tags.

The idea is simple: an NFC tag attached to the fridge allows any family member to instantly open the shopping list from their smartphone.

### Project Goals

- Manage shopping items.
- Share a common list between multiple users.
- Quick access through NFC.
- Android and iPhone compatible.
- Simple and responsive interface.
- Learn web development, databases and NFC technologies.
